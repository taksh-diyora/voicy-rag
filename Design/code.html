Explain the multi-head self-attention mechanism in Section 3.2 and why projection matrices W_Q, W_K, W_V are used.

23:14:08done_all
Shivani • Synthesizing
linkVaswani et al., §3.2, p. 4

In Section 3.2, Multi-Head Attention allows the model to jointly attend to information from different representation subspaces at different positions. With single attention, averaging inhibits this.

W_Q

Query Projection: Transforms token embeddings into query subspaces, defining what each token is actively seeking.

W_K

Key Projection: Projects keys to match queries via scaled dot-product compatibility scores ($QK^T / \sqrt{d_k}$).

W_V

Value Projection: Linear transformation of the actual informational payload aggregated into the final weighted sum.

MultiHead(Q, K, V) = Concat(head_1, ..., head_h) * W_O
where head_i = Attention(Q * W_Q_i, K * W_K_i, V * W_V_i)

Instead of performing a single $d_{model}$-dimensional attention function, linearly projecting queries, keys, and values $h$ times with distinct learned projections yields superior cross-positional resolutions without computational latency.
